- Algorithm:
  - average = sum(len*score)/sum(len) over segments with a score.
  - coverage_pct = covered length / length with known coverage. Segment covered = open place at arrival or help point within 75 m of its path; False only if places and area data both available and nothing could count; unknown-hours place nearby or missing dataset = None.
  - longest gap = longest run of consecutive `covered == False` segments, summed in meters; None breaks the run.
  - worst window = min over window starts of the length-weighted mean of known scores in [s, s+200]. Candidate starts = every segment boundary and boundary-200, clipped to [0, L-200] (exact, since the mean is piecewise linear between those). Route <= 200 m: whole route.
  - penalty = max(0, gap-150)*0.1; applied = min(penalty, base).
  - route_score = clamp(0.5*avg + 0.5*worst - applied, 0, 100); null if no segment has a score.
  - Unknown: left out of avg/window, share reported in `unknown_length_m` + `notes`.
